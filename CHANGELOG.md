# Changelog

## 1.2.0
- Replaced model names with Model A–E in the bundled example.
- Retained supplied numeric data, axes, colors, anchors and annotation/style parameters.
- Removed project-specific presets and previews from the distributable package.
- Updated CLI to use a generic `example` preset.

## 1.0.0
- Added smooth-radar dual-anchor radar rendering with centripetal Catmull–Rom interpolation.

## 1.2.0
- Set Arial as the default font for all chart text.
- Added explicit sans-serif fallbacks for systems without Arial.
