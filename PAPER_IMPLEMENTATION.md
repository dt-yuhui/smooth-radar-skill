# Example configuration provenance

The anonymized example retains the numeric values, axis order, colors, group colors, scale anchors, curve settings and annotation settings from the JSON supplied in the conversation. Only model names were replaced with Model A–E, and the title/subtitle were generalized.

The figure combines `dual_anchor_custom` radial mapping with a closed `centripetal_catmull_rom` curve (`alpha=0.5`, 40 samples per segment). The word periodic refers to curve closure, not a periodic anchor pattern.

The example's line widths, marker size, font sizes, label radius, tie tolerance and label offsets are retained from the supplied configuration.

Per-axis anchors preserve within-axis ordering but make cross-axis radii non-comparable. Radar area is not an overall score.
